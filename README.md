# Wayfarer — Travel & Tour Agency

A responsive multi-page travel agency website made with HTML5, CSS3 and Vanilla JavaScript.

## Pages
1. Home (`index.html`)
2. Destinations (`destinations.html`)
3. Packages (`packages.html`)
4. Destination Details (`destination-details.html`)
5. Booking (`booking.html`)
6. Travel Journal (`travel-blog.html`)
7. Contact (`contact.html`)
8. About (`about.html`)

## Interactive features
- Responsive mobile navigation
- Home page hero image slider
- Destination search and filtering
- Package cost calculator (travellers × nights × per-person nightly rate)
- Testimonial carousel
- Booking form validation (required fields, email, 10-digit phone, future date and traveller range)
- Contact form validation

## Run locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Notes
- This is a front-end academic project. Booking and contact forms validate in the browser but do not send data to a server.
- Destination photographs and Google Fonts load from external services, so an internet connection is required for those assets.
- Package prices are sample values for the demonstration and should not be treated as live travel quotes.
